      What this shows

      1. “Shortest” depends on what you count. BFS counts turns, so it often walks further. Dijkstra and A* count metres.
      2. A* does the same job with less work. It aims at the flag, so it skips streets heading the wrong way. Across 300 random walks it checked a median of 77% fewer junctions than Dijkstra for exactly the same route.
      3. The answers are checked. Every route matches NetworkX, an independent graph library, on all 300 test walks.

      How each one counts

      BFS counts street segments, so it takes the route with the fewest of them. Dijkstra and A* count metres. A* also aims at the destination using the straight-line distance to it, which can never be longer than the real walk, so its route is still the shortest.

      Why does A* search less?

      The same three searches on a small hilly grid, where you can see every cell they look at and the queue behind each step.
